# rusty messenger

Краткое описание:

Высоконагруженный мессенджер на Rust. Написанный в рамках изучения современного стэка бэкенд-разработки.

## Автор
    Голяченко Андрей (Bartiam)

## Статус
    Учебный проект (в разработке)

## Возможности на данный момент
    - HTTP-сервер на Axum с маршрутами /health и /users.
    - Конфигурация через переменные окружения и .env (Clap + dotenvy).
    - Graceful shutdown - корректное завершение при получении SIGINT/SIGTERM.
    - Структурированная обработка ошибок через кастомный тип AppError с трансформацией в HTTP-ответы.
    - Docker-образ минимального размера (multi-stage build).
    - Деплой - контейнер запускается на порту, указанном в .env (или по умолчанию 3000).
