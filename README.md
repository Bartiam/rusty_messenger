# rusty messenger

Краткое описание:

Высоконагруженный мессенджер на Rust. Написанный в рамках изучения современного стэка бэкенд-разработки.

## Автор
    Голяченко Андрей (Bartiam)

## Статус
    Учебный проект (в разработке)

## Технологический стек
    - Язык: Rust (edition 2024)
    - Веб-фреймворк: Axum
    - База данных: PostgreSQL (драйвер SQLx)
    - Асинхронность: Tokio
    - Логирование и трассировка: Tracing + Tower HTTP
    - Конфигурация: Clap + dotenvy
    - Контейнеризация: Docker (multi-stage build)

## Возможности на данный момент
    - HTTP-сервер на Axum с обработкой запросов.
    - Маршруты:
        - GET /health - проверка работоспособности сервера (возвращает "OK").
        - GET /health/db - проверка соединения с базой данных (возвращает статус подключения).
        - POST /users - заглушка для создания пользователя (временный ответ с информацией о порте; полноценная реализация в процессе).
    - Конфигурация через переменные окружения (поддержка .env файла) - порт и URL базы данных.
    - Graceful shutdown - корректное завершение работы при получении сигналов SIGINT/SIGTERM.
    - Структурированная обработка ошибок - кастомный тип AppError с автоматическим преобразованием в HTTP-ответы и логированием внутренних ошибок.
    - Логирование HTTP-запросов через middleware TraceLayer.
    - Схема базы данных (миграции) – подготовлены таблицы для:
        - пользователей (users),
        - чатов (chats),
        - участников чатов (chat_members),
        - сообщений (messages).
    - Docker-образ с multi-stage сборкой для минимального размера.
